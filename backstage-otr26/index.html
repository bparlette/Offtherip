Hand this to an AI

  1. Click Copy full AI brief (or open brief.md) and paste it into the AI as its first message.
  2. Tell it which task to do, for example: "Do task T03. Stop at every needs_human step and tell me what to enter." A browser-control agent (Muse, Claude with Chrome, Operator and similar) can drive the registrar, Cloudflare, Kit and social sign-up pages. You still type passwords, 2FA codes and payment details.
  3. For coding tasks give it the repo: npm run dev to preview, npm test before committing.
  4. Each task card has a Copy for AI button with just that task plus the rules.
  5. When it finishes, ask it to set the task's status and notes in src/hq/tasks.json and rebuild. The checkmarks on this page are saved in your browser only; tasks.json is the shared source of truth.
